Sub2API 联动服务配置说明
管理员 Key 仅用于后台同步账号和凭据；公开控制 Key 只用于访客启停调度与恢复临时状态。

这不是普通用户调用模型的 API Key。Sub2API 发布版 v0.2.18 仍没有受限密钥；若你使用包含该功能的开发版， 可在「系统设置 → 安全 → 管理员访问密钥」创建 adm_sc_ 受限管理员 Key，只授予 accounts.read、 accounts.status、accounts.recover。 若版本不支持受限 Key，请留空以复用管理员 Key；服务端只会调用固定的账号读取、调度和恢复接口，管理员 Key不会返回浏览器。

管理员 Key和独立控制 Key均未配置时，公开卡片只允许查看，不会显示调度与恢复操作。

当前公开控制使用的是高权限管理员 Key，仅用于兼容旧配置。请创建并改用 adm_sc_ 受限管理员 Key，避免公开控制路径持有超出所需的后台权限。

当前未配置独立控制 Key，公开控制将复用管理员 Key。请确认只对需要公开控制的账号开启“允许公开调度/恢复”，并保留管理员硬锁。

定时刷新时，距上次 Sub2API 同步超过该间隔才会再次同步（60–86400，默认 900）。管理员点击“刷新数据”或进入页面时会立即同步一次，不受此间隔限制。
